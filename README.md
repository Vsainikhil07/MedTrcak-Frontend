# MedTrack – Frontend

MedTrack is a healthcare management application built using React.js and Vite.

## Features

- Medicine management
- Prescription management
- Medicine reminders
- Pharmacy locator

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal to access the application.
